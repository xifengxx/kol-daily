概念卡片
💡 一句话

把光模块直接"焊"在芯片旁边，用光代替电来传输数据

Co-Packaged Optics (CPO) — 将光学引擎与交换芯片/GPU封装在同一基板上，省去传统可插拔光模块的电信号走线损耗

🏠 生活类比

以前快递到了要去小区门口驿站取（传统光模块在面板），现在快递驿站直接搬进了你们小区的单元楼，走路距离从500米缩短到5米。

传统方案: 交换芯片 → PCB走线(5-10cm) → 可插拔光模块 → 光纤
CPO方案: 交换芯片 + 光学引擎(共封装) → 光纤 (走线<1cm)

🏭 产业链位置
L1 原材料 → L2 设备/器件 → 光模块 → CPO → L3 系统集成 → L4 应用

CPO属于L2设备层的"下一代光互连"方向，从可插拔光模块(800G/1.6T)演进到共封装，是AI数据中心高带宽低功耗的关键技术路径
