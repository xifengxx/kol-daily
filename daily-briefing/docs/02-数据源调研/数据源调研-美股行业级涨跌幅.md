## 二、FMP 行业级端点实测记录（2026-09-10）

### 2.1 `GET /stable/industry-performance-snapshot`

```
GET https://financialmodelingprep.com/stable/industry-performance-snapshot?date=2026-09-09&exchange=NASDAQ&apikey=KEY
```

- **返回字段**：`date` / `industry`（英文行业名）/ `exchange` / `averageChange`（等权平均涨跌幅，百分比）
- **NASDAQ**：126 个行业；**NYSE**：128 个行业（`exchange` 参数一次只接受一个交易所，传 `NYSE,NASDAQ` 返回空）
- **粒度**：GICS 行业级（Industry，三/四级之间），与富途热力图粒度一致
- **科技相关行业实测值（2026-09-09，NASDAQ 口径）**：
  - Semiconductors **+0.98%**（注意：费半指数同日 +0.37%，口径为等权平均 vs 市值加权指数，不可混用）
  - Communication Equipment +0.53%、Computer Hardware +0.44%、Software - Services +0.59%
  - Software - Application -1.28%、Software - Infrastructure -0.33%
  - Consumer Electronics -0.02%、Internet Content & Information +0.26%
  - Electronic Gaming & Multimedia -0.45%、Technology Distributors -0.88%
  - Telecommunications Services -2.30%
- **传统行业覆盖完整**：Oil & Gas 四个子行业、REIT 八个子类、Medical 十个子类、银行/保险/零售/汽车/航空等，合计 126+

### 2.2 `GET /stable/historical-industry-performance`

```
GET https://financialmodelingprep.com/stable/historical-industry-performance?industry=Semiconductors&from=2026-09-01&to=2026-09-09&apikey=KEY
```

- 返回该行业逐日 `averageChange` 时间序列，可算 N 日动量/连续强弱

### 2.3 已知局限

1. **NASDAQ / NYSE 分表**：同一行业两所数值差异可能很大（Advertising Agencies：NASDAQ -0.20% vs NYSE -2.09%），需定合并规则（简单平均 / 分开列示）
2. **等权平均含微盘股**：FMP 全量成分等权，小票噪声大（Oil & Gas Integrated -6.66% 或由小票驱动，与 XOM/CVX 权重口径差异明显），解读时须标注"等权口径"
3. **无成分股明细**：该端点不给行业内领涨/领跌个股，领涨代表仍需 `biggest-gainers/losers` 或自选股行情补充
4. **英文名**：需一次性建立 ~130 行业的英→中映射表（可对照富途/GICS 中文译名）
5. `available-industries` 端点当前订阅不可用（不影响主流程）

## 三、两个方案的对比（行业直取 vs 产业链自建）

| 维度 | 方案 A：FMP 行业直取 | 方案 B：产业链自建聚合（前次方案） |
|------|---------------------|--------------------------------|
| 覆盖广度 | ✅ 全市场 126 行业 | ❌ 只有策展的赛道 |
| 精细题材（HBM/光模块/液冷/CoWoS） | ❌ 拿不到（归在 Semiconductors/Communication Equipment 大类） | ✅ 精确到环节 |
| 维护成本 | ✅ 零维护（标准分类） | ⚠️ 需维护成分股清单 |
| 数据稳定性 | ✅ 付费 API | ⚠️ 取决于成分股行情接口（稳定但日韩有缺口） |
| 加权方式 | 等权（FMP 固定口径） | ✅ 可自选等权/市值加权 |
| 中文 | ❌ 需映射表 | ✅ 自定 |
| 领涨领跌个股 | ⚠️ 需补充接口 | ✅ 天然带成分股明细 |

**推荐：A 为主 + B 为精简叠加**

1. **主力（行业热力榜）**：每日 2 次请求拉 NASDAQ+NYSE 全行业快照 → 合并 → 中文映射 → 晨报新增「行业热力图」章节（Top 涨/跌行业 + 科技行业明细 + 等权口径标注）
2. **叠加（可选，AI 链精细环节）**：仅对 GICS 行业颗粒度不够的 8-10 个核心环节（HBM、光模块、AI 服务器、液冷散热、先进封装、半导体设备、EDA、云计算大模型）自建小清单聚合，承接产业链方案但范围大幅收缩
3. **领跌警示**：M7 + 叠加清单成分股中 |涨跌| ≥ 5% 的自动标记（Vertiv 类信号）

## 四、实施要点

1. **脚本**：扩展 `fetch_us_market_data.py` 新增 industry 模块（NASDAQ+NYSE 两次请求，合并去重，输出 `industry_heat` 到 JSON 快照）

3. **报告章节**：提示词模板「市场状态总览」的板块涨跌全景升级为行业热力榜（Top 8 涨 + Top 8 跌 + 科技行业全列），表格口径注明"FMP 等权平均，NASDAQ/NYSE 合并口径"
4. **工作量**：映射表 + 脚本扩展 + 提示词更新 ≈ 半天到一天
