## 二、数据源一：Infoway 调研结果

### 2.1 数据源概述

| 项目 | 内容 |
|---|---|
| 文档站 | `https://docs.infoway.io/`（含 `llms.txt` 完整索引，`.md` 后缀可看 Markdown） |
| REST Base URL | `https://data.infoway.io` |
| WebSocket URL | `wss://data.infoway.io/ws?business={stock\|crypto\|japan\|india\|korea\|common}&apikey=YourAPIKey` |
| 新闻 WS（独立） | `wss://data.infoway.io/news?apikey=YourAPIKey` |
| 认证方式 | REST：HTTP header `apiKey`；WS：query 参数 `apikey`；支持环境变量 `INFOWAY_API_KEY`；`lang` 参数可切换 `en`/`zh-CN` |
| 开通方式 | infoway.io 官网申请 API Key，有免费套餐/7 天试用 |
| 语言绑定 / SDK | Python（`pip install infoway-sdk`）、Node.js（`npm install infoway-sdk`，≥18）、Java、MCP Server（`uvx infoway-mcp-server`，17 个工具） |
| 协议 | REST + WebSocket（Trade / Depth / K线 / News 四个订阅频道，心跳协议号 10010） |
| 核心 REST 端点族 | `POST /{market}/v2/batch_kline`（K线，body 传 `klineType`1–12、`klineNum`≤500、`codes`≤100、`timestamp` 回溯）、`GET /{market}/batch_trade/{codes}`、`GET /{market}/batch_depth/{codes}`；market ∈ {stock, japan, india, korea, crypto, common(外汇/商品/期货)} |

### 2.2 15 类数据逐项结论

| # | 数据类别 | 支持度 | 具体接口 | 备注 |
|---|---|---|---|---|
| A | 美股指数（SP500/纳指/道指/SOX/罗素/VIX） | 部分 | 指数列表 `GET /common/v2/basic/market/indexes`（`IX/US/.SPX`=标普500、`.IXIC`=纳指、`.DJI`=道指）；行情 `POST /stock/v2/batch_kline`（点号前缀代码） | SPX/IXIC/DJI 已确认；SOX、罗素2000、VIX 文档未出现，需用 symbol-list 实测 |
| B | 美股个股实时/历史（含盘前盘后） | 支持 | `POST /stock/v2/batch_kline`（`klineType=8` 日线）、`GET /stock/batch_trade/{codes}`、`GET /stock/batch_depth/{codes}` | 代码如 `NVDA.US`/`AAPL.US`；交易时段含 PreTrade 04:00–09:30、NormalTrade 09:30–16:00、PostTrade 16:00–20:00 |
| C | 全市场/指数成交量、量比 | 部分 | K线返回单标的 `v`(成交量)、`vw`(成交额) | 无全市场总量聚合、无现成量比指标，需自行取 20 日 K 线算均值 |
| D | 市场宽度（涨跌家数） | **支持** | `GET /common/v2/basic/market/breadth/{market}`，`market=US` | 返回 `rise_less_than_three`/`rise_three_to_five`/…/`fall_*`/`flatline` 分档家数，原生接口 |
| E | 标普 11 大行业板块每日涨跌 | 部分 | `GET /common/v2/basic/plate/industry/US`（含 `chg`、`last_done`、`rise`/`fall`、`total_amount`、`market_cap`）；领涨行业 `GET /common/v2/basic/market/leaders/US?limit=10` | 板块编码为 Infoway 自定义 `IN{code}.US`，未文档化为标普 GICS 11 行业，需自行映射 |
| F | 行业 ETF 资金流 | 部分 | XLK/XLF/XLE 可用 `batch_kline`/`batch_trade` 拿价格与量 | 只有价格/量，无资金净流入流出数据，全文档无 fund-flow 接口 |
| G | 期权（链/P-C比/IV） | 不支持 | 无 | 50 页文档 sitemap 无任何期权内容 |
| H | 恐慌贪婪指数 / 情绪 | 部分 | `GET /common/v2/basic/market/temperature?market=US`，返回 `temp`(0–100)、`temp_intro`、`valuation`、`sentiment` | 自研"市场温度"指标，不是 CNN Fear & Greed |
| I | 美联储利率概率（FedWatch） | 不支持 | 无 | 无任何 FedWatch/利率期货概率数据 |
| J | 美股股指期货（E-mini） | 不支持（未确认） | 期货走 `common`：`POST /common/v2/batch_kline`、`GET /common/batch_trade/{codes}`、`GET /common/batch_depth/{codes}`；产品列表 `GET /common/basic/symbols?type=FUTURES` | 主打商品（金/银/油），ES/NQ 代码需实测 symbol-list 确认 |
| K | 大宗商品（原油/黄金） | 支持 | `POST /common/v2/batch_kline` 等；产品列表 `GET /common/basic/symbols?type=ENERGY`/`FUTURES`/`METAL` | 黄金 XAUUSD、白银 XAGUSD 官方示例已确认；原油具体代码需查产品列表 |
| L | 外汇与美元指数 | 部分 | `POST /common/v2/batch_kline` 等；产品列表 `GET /common/basic/symbols?type=FOREX` | 40+ 主流货币对（EURUSD、USDCNY、USDJPY 等）；美元指数 DXY 未确认 |
| M | 加密货币（比特币） | 支持 | `POST /crypto/v2/batch_kline`、`GET /crypto/batch_trade/{codes}`、`GET /crypto/batch_depth/{codes}`；WS `business=crypto` | BTCUSDT 官方示例确认，覆盖 100+ 主流币 |
| N | 经济日历 / 宏观数据 | 不支持 | 仅新闻 WS `wss://data.infoway.io/news`（实时快讯） | 只有快讯新闻流，无经济日历、无宏观指标字段 |
| O | 美债收益率（2Y/10Y/30Y） | 不支持（未确认） | 无专门接口；理论上可查 `GET /common/basic/symbols?type=FUTURES` | 文档 sitemap 无美债/收益率内容 |

### 2.3 一句话结论

**Infoway 最适合覆盖"美股日度复盘"的行情与市场结构层**——个股实时/历史行情（含盘前盘后）、SP500/纳指/道指、涨跌家数、行业板块涨跌、市场温度情绪、以及黄金/原油/外汇/比特币等跨资产价格，全部有真实接口；**但它完全缺宏观层（经济日历、CPI/非农/PCE、FedWatch 利率概率）与衍生品层（期权链/P-C比/IV、ETF 资金流）**，且 VIX、罗素2000、SOX、美元指数、ES/NQ 股指期货、美债收益率均未在文档中确认（需用 `GET /common/basic/symbols?type=INDICES|FUTURES|FOREX` 实测产品清单后才有定论）。

## 三、数据源二：FMP 调研结果

### 3.1 数据源概述

| 项目 | 说明 |
|---|---|
| Base URL（新 stable 版） | `https://financialmodelingprep.com/stable/...`（官方推荐，文档已全面迁移） |
| Base URL（旧版） | `https://financialmodelingprep.com/api/v3/...`（存量订阅仍可用） |
| 认证方式 | 每次请求携带 `?apikey=YOUR_KEY`。`demo` 公共 key 已失效（实测返回 `Invalid API KEY`） |
| 免费/付费限制 | 免费版 250 请求/天、仅 EOD、美股上市公司、约 5 年历史、>150 个端点。Starter≈300 req/min、Premium≈750、Ultimate≈3000。**期权链、盘前盘后、经济日历、日内数据、ETF 持仓等均为付费端点** |
| 数据覆盖面 | 股票、ETF、共同基金、指数、外汇、加密、商品（含商品期货）、宏观经济。**不含 CME 股指期货（ES/NQ）、不含 FedWatch、不含恐慌贪婪指数、无全市场涨跌家数聚合** |

> 调研说明：主文档 `site.financialmodelingprep.com/developer/docs` 对抓取工具返回 403。改用官方文档镜像 `intelligence.financialmodelingprep.com/developer/docs/stable/{slug}`（浏览器 UA + 解析 `__NEXT_DATA__` JSON）、官方 sitemap（`site.financialmodelingprep.com/sitemap-{1..8}.xml`，280 个 stable 端点 slug）及多个第三方封装库交叉验证。

### 3.2 15 类数据逐项结论

| # | 数据类别 | 支持度 | 具体接口路径 | 参数要点 | 备注 |
|---|---|---|---|---|---|
| A | 美股指数行情 | ✅ | `/stable/quote?symbol=^GSPC,^IXIC,^DJI,^SOX,^RUT,^VIX`；历史 `/stable/historical-price-eod/full?symbol=^GSPC&from=&to=`；日内 `/stable/historical-chart/5min?symbol=^VIX`；`/stable/index-list` | `symbol`(带 `^`)、`from`/`to`(YYYY-MM-DD) | VIX 官方文档即用 `^VIX` 作示例；`^SOX`、`^RUT` 为标准指数代码 |
| B | 个股实时/历史（含盘前盘后） | ✅ | 实时 `/stable/quote?symbol=AAPL`；历史 `/stable/historical-price-eod/full`；日内 `/stable/historical-chart/5min?symbol=AAPL&extended=true`；盘前盘后专用 `/stable/pre-post-market-quote`、`/stable/aftermarket-quote`、`/stable/aftermarket-trade`、`/stable/batch-aftermarket-trade` | `symbol`、`from`/`to`、`extended` | 普通 `/quote` 不含盘前盘后，需 aftermarket 系列端点（付费），免费版仅约 84 只测试股 |
| C | 全市场/指数成交量、量比 | ⚠️ | 个股/指数量 `/stable/quote`、`/stable/historical-price-eod/full`（含 `volume` 字段）；高成交榜 `/stable/most-actives` | `symbol` | 无全市场总量聚合；量比需用历史 volume 自行计算 |
| D | 市场宽度（涨跌家数） | ❌ | 无专用端点。最接近：`/stable/biggest-gainers`、`/stable/biggest-losers`、成分股 `/stable/sp500-constituent` 等 | — | 无即拿即用的 A/D 数据，需拉成分股全表自行统计 |
| E | 标普 11 大行业每日涨跌 | ✅ | 当日 `/api/v3/sector-performance`（免费，每分钟刷新）；快照 `/stable/sector-performance-snapshot?date=&exchange=&sector=`；历史 `/stable/historical-sector-performance?sector=Energy&from=&to=`；`/stable/available-sectors` | `date`、`exchange`、`sector` | 返回各 sector 的 `averageChange`/`changesPercentage`；11 大行业口径齐全 |
| F | 行业 ETF 资金流 | ⚠️ | 持仓 `/stable/etf-holder-bulk?part=1`（旧 `/api/v3/etf-holder/{symbol}`）；板块权重 `/stable/etf/sector-weightings?symbol=SPY`；批量报价 `/stable/batch-quote?symbols=XLK,XLY,SPY` | `symbol`、`part` | 无"资金净流入"端点，只能拿持仓/权重/价格，资金流方向需自建推断 |
| G | 期权（链/P-C比/IV） | ⚠️ | 期权链 `/api/v3/options/chain/{symbol}?expiration=YYYY-MM-DD`（付费）；到期日 `/api/v3/options/available-expirations/{symbol}`；历史期权（旧版）`/api/v3/historical-options/{symbol}/{date}` | `symbol`、`expiration` | 链字段含 `contractSymbol,strike,lastPrice,bid,ask,volume,openInterest,impliedVolatility,inTheMoney,contractSize,currency,expirationDate,optionType`；无现成 Put/Call 比率端点，需对当日期权链自行聚合 |
| H | 恐慌贪婪指数 / 情绪 | ❌ | 无 CNN Fear & Greed 或等效指数。情绪替代：`/api/v4/historical/social-sentiment?symbol=`（付费）、COT 报告 `/stable/cot-report`、`/stable/market-risk-premium` | `symbol`、`from`/`to` | 想做恐慌/贪婪需另接数据源 |
| I | 美联储利率概率（FedWatch） | ❌ | 仅有实际利率指标 `/stable/economic-indicators?name=federalFunds` | `name=federalFunds` | FedWatch 概率需用 CME 官方 FedWatch API（另购，$25/月起） |
| J | 美股股指期货（ES/NQ） | ❌ | FMP 资产类别仅 STK/ETF/MTF/CMDTY/FX/CRYPTO/INDEX，无 CME 股指期货价格流 | — | 只能拿现货指数 `^GSPC`/`^IXIC` 作代理 |
| K | 大宗商品（原油/黄金） | ✅ | `/stable/quote?symbol=CLUSD`（WTI）、`BZUSD`（布伦特）、`GCUSD`（黄金）；历史 `/stable/historical-price-eod/full?symbol=GCUSD`；日内 `/stable/historical-chart/5min?symbol=GCUSD`；`/stable/commodities-list` | `symbol` | FMP 商品即"商品期货"口径 |
| L | 外汇与美元指数 | ⚠️ | `/stable/quote?symbol=EURUSD`；`/stable/forex-list`、`/stable/historical-price-eod/full?symbol=EURUSD`、`/stable/batch-forex-quotes`（付费） | `symbol` | DXY 美元指数未确认有专门端点，需查 `/stable/index-list` 是否含 `^DXY` |
| M | 加密货币（比特币） | ✅ | `/stable/quote?symbol=BTCUSD`；`/stable/cryptocurrency-list`、历史/日内齐全 | `symbol` | 免费可用 |
| N | 经济日历/宏观数据 | ✅ | `/stable/economic-calendar?country=US&from=&to=`（付费）；指标 `/stable/economic-indicators?name=GDP|CPI|inflationRate|unemploymentRate|initialClaims|totalNonfarmPayroll|federalFunds|...` | `country`、`from`/`to`、`name` | 日历字段含 `date,country,currency,event,actual,estimate(预期),previous(前值),impact,change`——正合复盘"实际/预期/前值"需求 |
| O | 美债收益率（2Y/10Y/30Y） | ✅ | `/stable/treasury-rates?from=&to=`（旧 `/api/v4/treasury`） | `from`/`to` | 返回全期限 1m/3m/6m/1y/2y/3y/5y/7y/10y/20y/30y（字段 `year_2`/`year_10`/`year_30` 等） |

### 3.3 一句话结论

**FMP 最擅长：指数/个股/ETF 行情与历史（含 `^VIX`）、11 大板块每日涨跌幅、美债收益率、大宗商品（CLUSD/GCUSD/BZUSD）、外汇、比特币、经济日历（实际/预期/前值）——足以覆盖美股日度复盘的核心行情+宏观部分；但缺全市场涨跌家数、量比、ES/NQ 股指期货、FedWatch 加息概率、恐慌贪婪指数、直接资金流与历史 Put/Call 比，这几项需另接数据源。**

## 四、数据源三：同花顺 iFinD 调研结果

### 4.1 数据源概述

| 项目 | 说明 |
|---|---|
| 入口/域名 | 官网营销页 `quantapi.51ifind.com/gwstatic/static/ds_web/quantapi-web/`；HTTP API 主域 `https://quantapi.51ifind.com/api/v1/`（备用 `ft.10jqka.com.cn`） |
| 支持语言 | Python（iFinDPy SDK）、MATLAB、R、VBA、C++、C#、Java；另有 HTTP REST API（无需本地 SDK）和 Excel 插件 `thsiFinD` |
| 认证方式 | SDK 用 `THS_iFinDLogin(账号, 密码)` 登录；HTTP 用长期 `refresh_token` 换取 7 天有效的 `access_token`（单个 token 限 20 个 IP） |
| 安装 | `pip install iFinDAPI`，或从 `quantapi.10jqka.com.cn` 下载 SDK |
| 核心函数族 | `THS_BD`(基础数据) / `THS_DS`(日期序列) / `THS_HQ`(历史行情) / `THS_RQ`(实时行情) / `THS_HF`(高频) / `THS_SS`(快照) / `THS_EDB`(经济数据库) / `THS_DP`(数据池) / `THS_WC`(问财)；HTTP 对应 `basic_data_service`、`date_sequence`、`cmd_history_quotation`、`real_time_quotation`、`high_frequency`、`snap_shot`、`edb_service`、`data_pool`、`smart_stock_picking` 等 |
| 市场覆盖 | A股、港股、美股、基金、债券、期货、期权、外汇、指数、全球宏观；交易日历支持 NYSE/NASDAQ/CME/COMEX/NYMEX/ICE 等全球交易所 |
| 证券代码格式 | A股 `000001.SZ`、港股 `00700.HK`、美股 `AAPL.O`（SDK）/`AAPL.US`（Excel）、指数 `000001.SH`；可用 `get_thscode` 做代码互转 |
| 账号权限影响 | 免费版：美股行情延时 15 分钟、历史仅最近 5 年、实时订阅≤3 只、月度配额受限；正式版才提供美股实时与全历史 |

> ⚠️ 函数名澄清：调研确认 `THS_iFinDSecurityQuote`、`THS_iFinDIndex` 并不是真实存在的函数名。iFinD 的真实函数族为 `THS_BD/THS_DS/THS_HQ/THS_RQ` 等；"证券行情报价"对应 `THS_RQ` + 字段，"指数行情"对应 `THS_DS`/`THS_HQ` + `ths_close_price_index` 等指标。

### 4.2 15 类数据逐项结论

| # | 数据类别 | 支持度 | 具体函数 / 参数 | 备注 |
|---|---|---|---|---|
| A | 美股指数行情 | 部分 | `THS_DS`/`THS_HQ`/`THS_RQ` + 指数代码 + `ths_close_price_index,ths_pre_close_index` 等 | iFinD 终端"全球指数报价"确认可看道琼斯/标普/纳指，VIX 可用代码 `VIX`/`^VIX`；API 侧美股指数具体代码官方手册未给示例，需 `get_thscode` 查询；免费账号延时 15 分钟 |
| B | 美股个股实时/历史（含盘后） | 支持（盘后部分） | `THS_RQ('AAPL.O','latest,changeRatio,volume,amount')`；`THS_HQ`/`THS_DS` 取日线；盘后字段 `post_lastest,post_volume,post_amt,post_dealnum` | 支持盘后(post_*)指标；"盘前"字段未单独证实；免费版延时 15 分钟 |
| C | 全市场/指数成交量、量比 | 部分 | `THS_HQ`/`THS_RQ` 的 `volume,amount`（指数也返回）；量比 `vol_ratio`（实时，股票字段） | 指数成交量/成交额可取；`vol_ratio` 以 A股为主；美股全市场总成交量无现成汇总 |
| D | 市场宽度（涨跌家数） | 部分 | `THS_RQ` 实时字段 `riseCount,fallCount,upLimitCount,downLimitCount,suspensionCount`（标为"指数专用"） | A股指数可用；美股指数是否计算该字段官方未证实 |
| E | 标普 11 大行业每日涨跌 | 部分（需自建） | 无现成"S&P 11 行业"接口；可用 `THS_DP('block',…)` 取板块成分 + `THS_BD`/`THS_DS` 取成分股行情，再按 GICS 自聚合 | 板块分析主要面向 A股（申万等）；美股 GICS 行业指数现成 API 序列未见 |
| F | 行业 ETF 资金流 | 不支持 | 资金流指标 `mainInflow/mainNetInflow/largeNetInflow…`（A股股票导向）；美股 ETF 仅少量美国基金指标 | 美股行业 ETF 的申赎/资金流数据未见于 API |
| G | 期权（链/P-C/IV） | 部分 | `THS_RQ` 期权字段 `impliedVolatility,historyVolatility,delta,gamma,vega,theta,rho,volume_pcr_total,volume_pcr_month,openInterest,expiryDate` | 主要面向 A股/股指期权（50ETF/沪深300/CFFEX）；美股期权链（SPY）未证实 |
| H | 恐慌贪婪指数 / 情绪 | 不支持 | 无 | 无 CNN Fear & Greed；可用 VIX 近似替代 |
| I | 美联储利率概率 | 部分（仅利率水平） | `THS_EDB` 查"美国联邦基金目标利率/联邦基金利率(日)" | CME FedWatch 式"加息概率"未见提供 |
| J | 美股股指期货（ES/NQ） | 部分 | `THS_HQ` 期货字段 `openInterest,positionChange,preSettlement,settlement,change_settlement,amplitude`；`THS_DateQuery` 支持 CME/CBOT | iFinD 终端"全球指数→美股期货"确认有；API 侧 ES/NQ 具体代码需 `get_thscode` 查询 |
| K | 大宗商品（原油/黄金） | 部分 | `THS_HQ` 期货字段；交易所列表含 NYMEX(WTI)、ICE(布伦特)、COMEX(黄金)；`THS_EDB` 亦可取商品价格序列 | 具体代码（如 CL/GC/BRN）需 `get_thscode` 或终端查询 |
| L | 外汇与美元指数 | 部分 | `THS_HQ` 外汇字段 `close_2330`；`Currency` 参数支持 `MHB-美元`；EDB 可含美元指数/DXY | API 外汇/美元指数具体代码未文档化 |
| M | 加密货币（比特币） | 不支持 | 无 | 无加密货币品类 |
| N | 经济日历/宏观数据 | 部分 | `THS_EDB(indicators,'M001620326,…',start,end)`；HTTP `edb_service` | EDB 覆盖全球/美国宏观（60万+指标，450+数据源），美国 PMI/CPI/非农为 EDB 序列（历史实际值）；"预期值/前值"日历式字段未证实 |
| O | 美债收益率（2Y/10Y/30Y） | 支持 | `THS_EDB` 查美国国债收益率：1m/3m/6m/1y/2y/3y/5y/7y/10y/20y/30y（日频）、TIPS 收益率、实际收益率曲线 | EDB 全球宏观（美联储/美国财政部数据源）明确列出，为 15 类中覆盖最确定项之一 |

### 4.3 一句话结论

**iFinD quantapi 是 A股/港股的"原生主场"——美股个股行情、全球宏观（美债收益率/联邦基金利率/美国 PMI·CPI·非农）与 A股期权数据是其强项；但美股日度复盘所需的"细分弹药"（S&P 11 行业现成涨跌幅、美股行业 ETF 资金流、恐慌贪婪指数、美联储加息概率、加密货币、美股期权链、美股盘前）在 API 中基本缺位或未被文档化，且美股行情免费版延时 15 分钟、部分品种代码需二次查询，不建议作为美股日度复盘的唯一数据源。**

## 七、结论与建议

**1. 简报数据短板，两个源基本能补齐：**

- **主数据源 → FMP（付费档）**：指数、VIX、SOX、罗素、M7 个股、**11行业板块**、美债收益率、**经济日历（实际/预期/前值）**、期权链、商品/外汇/加密——一次覆盖缺失项 3/4/6/11/12/13 + 指数。
- **补缺数据源 → Infoway（免费档起）**：**涨跌家数（独家）**、盘前盘后行情、加密、自研情绪指标——补缺失项 2/13。

**2. 三个源都补不上的 4 块**（需另想办法）：

- FedWatch 利率概率 → 接 **CME FedWatch API**（另购）
- 恐慌贪婪指数 → CNN/Alternative.me 抓取，或用 Infoway "市场温度"近似
- E-mini 股指期货 → 实测 Infoway/iFinD 期货清单，不行就用现货指数 + 盘前数据代理
- 直接资金流 → 用 ETF 量价自建推断，或换专门的资金流源

**3. iFinD 的角色**：如果已有 iFinD 账号，适合当**宏观历史数据备份**（EDB 的 PMI/CPI/非农/美债收益率日频很全）；但不建议作为美股日报主源（延时、代码需二次查询、板块/加密/盘前缺位）。
