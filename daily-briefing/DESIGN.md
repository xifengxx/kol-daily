## 5. 内容区设计：卡片 + 模块化（核心）

**原则**：报告不是"一整块 markdown"，而是**按章节拆成独立卡片模块**，对齐 industry-chain 详情页的模块化视觉。

```
┌─ detail-header ─────────────────────┐
│  # 报告标题（大字号）                 │
│  meta：简报日期 · 对应交易日 · 编号   │
└─────────────────────────────────────┘
┌─ card.summary（今日一句话·高亮卡） ──┐
│  一句话总览（accent 左边框 + 浅蓝底）│
└─────────────────────────────────────┘
┌─ card（每个 ## 章节 = 一张卡片） ────┐
│  card-title：章节名                   │
│  章节正文：h3/h4 / 表格 / 列表        │
└─────────────────────────────────────┘
┌─ card（下一个章节）... ─────────────┐
```

### 5.1 章节解析规则

- 报告 `.md` 按 **`## `（二级标题）** 拆分成章节
- `# `（一级标题）→ `detail-header` 的标题
- 顶部 `**简报日期**：...` 等元数据行 → `detail-header` 的 meta 标签
- 每个 `## ` 章节 → 一张 `.card`，章节名 → `.card-title`
- **第一个章节**（今日一句话/总览）→ `.card.summary`（accent 左边框 + `--active` 浅蓝底，突出"核心洞察"）

### 5.2 报告 Markdown 样式规范

- **表格**：仿 `quality-table`——表头 `--bg` + 2px 下边框 + 大写浅灰；单元格 1px 分隔线；hover 行 `--bg`
- **h3**（卡内小节）：16px 加粗；**h4**：14px
- **涨跌色**：报告正文中的 `+X%` / `-X%` 用 `--up` / `--down` 语义（A股习惯红涨绿跌）
- **blockquote**：`accent` 左边框 + `--text2`
- **数据来源/口径说明**：次级文字 `--text2`

## 6. 响应式

- **≤768px**：侧栏收起为顶部横向选择器，内容单列，报告内边距收紧（20px→16px）
