## 一、行业动态（AIHOT）

### 1. OpenBMB 点评 InternLM 基于 MiniCPM-o 4.5 打造的 Sage-Interaction

**源站摘要**：OpenBMB 转发并点评上海人工智能实验室 InternLM 团队发布的开源全双工语音视频模型 Sage-Interaction，该模型基于 MiniCPM-o 4.5 构建。OpenBMB 称赞其边说边听、在不打断对话的情况下把复杂任务交给后端模型，是迈向更自然 AI 交互的一步，并向 InternLM 团队致意。

**我的点评**：全双工不是语音合成的一次升级，而是把「边说边听」和「被打断后接得上」变成架构问题：延迟预算、回声消除、轮次判定都要重做。Sage 把复杂任务中途交给后端模型，说明前端管交互、后端管推理的分工在成型。开源是拿权重换生态，但基于 MiniCPM-o 4.5 意味着能力上限仍受小模型约束；真正要验的是多轮打断后的上下文一致性与端到端延迟，源站都没给。[待核实]（置信度：中）

## 二、技巧与观点（AIHOT）

### 1. 实测支付宝 SkillPay：手把手教你怎么把 Skill 挂上去卖钱

**源站摘要**：作者完整实测支付宝 SkillPay 平台的 Skill 变现流程，该平台7月上线，支持买断和订阅两种售卖模式。买断制将 Skill 完整内容交付本地，订阅制把 Skill 保留在云端沙盒中、Agent 看不到明文；买断定价 0.01-50 元，订阅按周月季度收费上限 50 元，免费试用最低 5 次。

**我的点评**：SkillPay 补的是 agent 生态最缺的一环：分发的结算。但买断 0.01–50 元、订阅上限 50 元，说明平台现在测的是流程而不是商业化。买断把完整内容交付本地，等于一次购买后护城河归零；订阅留在云端沙盒、Agent 看不到明文，才是可防守的形态，代价是执行延迟和本地工具权限受限。真正难的是退款与盗版举证——这两条没有规则，好 Skill 不会上来。（置信度：中）

### 2. Antigravity 实用技巧：在 GEMINI.md 加一句话让模型边干活边汇报

**源站摘要**：卡兹克分享一个 Antigravity 使用技巧，针对模型长时间闷头干活不输出信息的问题，只需在 GEMINI.md 中加一句话，要求动手前说要做什么、有发现、换方向、卡住或连干四五步时再说一句，即可获得类似 Claude 或 Codex 那种实时汇报进度的交互体验。

**我的点评**：这条技巧的本质是把「过程可见性」外包给模型自觉：动手前、有发现、换方向、卡住、连干四五步各说一句。对单 agent 的 IDE 会话确实够用，成本也低；但提示词约束在长上下文里会被稀释，步数一多模型照样闷头跑。更稳的做法是让工具调用本身产生结构化进度事件，再由界面渲染，而不是靠模型记得汇报。它适合当过渡方案，不适合当工程契约。（置信度：高）
