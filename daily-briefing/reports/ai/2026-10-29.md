**源站摘要**：Google DeepMind 发布 Gemini 4 Carbon，定位为最强前沿模型，主打网络安全与长程智能体能力，在 SEC-bench Pro 88.2%、ExploitGym 54.8%、CWE-bench 71.0% 取得领先，并以 59 分登顶 Artificial Analysis Intelligence Index v5.0。

### 2. 面壁智能发布并开源 MiniCPM-OCR 系列：1.3B 解析模型与 2B 判别模型

**源站摘要**：面壁智能发布并开源 MiniCPM-OCR 系列。MiniCPM-OCR 1.0（1.3B）在 Real5-OmniDocBench 取得 93.68 分、OCRBench v2 取得 54.7 分的 SOTA，经 DSpark 加速后吞吐达 1.217 页/秒，端到端效率提升 55%。

### 1. Claude Code 触发用量上限后如何用 OpenRouter 继续编码

**源站摘要**：OpenRouter 介绍 Claude Code 触发用量上限时改用 OpenRouter API key 继续编码的方法：设置三个环境变量或用 Ori Harness 的 ori claude 命令，即可按 token 付费使用同样的 Claude 模型，没有五小时和每周限制。

**我的点评**：对偶尔撞上限的人是实用解法：三个环境变量就切到按 token 计费，不再被五小时窗口卡住。但换算一下就知道，重度使用下按量付费几乎一定比订阅贵，它更适合偶发的冲刺而不是日常替代；另外请求改走 OpenRouter，数据路径和企业合规需要重新评估，团队环境里别默认这么干。[推测]（置信度：中）

### 2. Addy Osmani 讲解如何上手 Claude Code Mods

**源站摘要**：Addy Osmani 发布 Claude Code Mods 上手指南，说明 mods 是运行在会话中的 JavaScript/TypeScript 文件，可通过 hooks 观察事件、改写行为或渲染自定义界面。

**我的点评**：Mods 把扩展方式从配置文件推向可编程运行时：hooks 能观察事件、改写行为、渲染界面，等于给会话加了一层插件系统。能力越大，风险越具体——mod 是跑在会话里的任意 JS/TS，拥有工具调用权限，来源不明的 mod 就是一条新的供应链入口，分发与权限模型不解决，企业侧很难放行。适合先把重复的审查、格式化流程沉淀成 mod 的团队。[推测]（置信度：中）

### 3. OpenAI 员工撰文探讨 AI 进入企业组织架构的三种方式

**源站摘要**：OpenAI 员工 Hemanth Asirvatham 和 Elliott Mokski 发表下一篇经济系列文章，探讨 AI 进入企业组织架构的三种情形：在每位员工之下形成 AI 劳动力 basement、作为同事穿插在现有组织图中、以及夹在人类之间充当协调层。

**我的点评**：三种形态的差别不在技术，而在责任归属：放在每个员工脚下的「basement」最接近今天的助手，问责清晰；作为同事插进组织图，就得给 agent 定义权限、考核和出错归因；夹在人类之间做协调层，则要求它承担流程责任，失败时最难追。文章回避的是审计与权限模型，而这决定企业敢不敢让它接管跨部门流程。作者来自 OpenAI，视角也带着卖 token 的倾向。[推测]（置信度：中）
