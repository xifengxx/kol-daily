### 1. GitHub 用 Copilot 智能体将 Copilot 运行时从 TypeScript 迁移到 83 万行 Rust

**源站摘要**：GitHub 工程师 Stephen Toub 复盘用 Copilot 智能体在约 14.5 周内将 Copilot agent runtime 从 TypeScript/Node.js 全量重写为 832,378 行生产 Rust，AI 智能体完成大部分代码，共 128 个 PR 增量合入 main 并持续发布。

**我的点评**：14.5 周、83 万行、128 个 PR——真正可复用的是「128 个增量 PR 持续合入 main、持续发布」这个节奏，而不是 AI 写了多少行。全量重写最常死在长期分支上，把迁移切成随时可发布的小步，才是这个案例能走完的原因。给想模仿的团队提个醒：TypeScript 到 Rust 属于「有编译器兜底」的方向，编译器会替你抓出大量错误；换成动态类型语言之间的重写，同一套流程未必成立。（置信度：中）
