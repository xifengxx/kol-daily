### 1. 团队分享提升 Agent Harness Token 效率的提示词

**源站摘要**：一份公开提示词用于优化 LLM Agent Harness，目标是在不降低任务质量的前提下降低每任务的价格加权 token 成本。某团队一轮改动（提示词精简、工具卸载、缓存布局、稀疏行号、子智能体调优）将整体 token 成本降低约 7%，且质量无损。提示词强调按任务而非按请求计量，并建议先映射 harness、测量基线，再按优先级实施改动。

**我的点评**：这类内容的价值不在那 7%，而在方法：先映射 harness、测基线、再按优先级改，顺序颠倒就容易做出一堆无效优化。提示词精简、工具卸载、缓存布局、稀疏行号这些手段都不神秘，难的是「按任务而非按请求计量」这个口径——它把成本归因从单次调用拉到了完整任务链路，才是真正能指导决策的指标。7% 属于稳健改动，说明这类优化通常是多个小项叠加，而非找到一个杠杆点。[推测]（置信度：中）

### 4. Tomer Tunguz：AI 最重要的市场在中段而非前沿模型
