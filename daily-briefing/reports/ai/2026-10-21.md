## 一、模型发布/更新（AIHOT）

### 1. Inception Labs 发布扩散大语言模型 Mercury 3，速度达 1068 tokens/秒

**源站摘要**：Inception Labs 发布扩散式大语言模型 Mercury 3，称其在多项基准上超过 GPT-6 Luna 和 Claude Haiku 5.5，速度达 1068 tokens/秒，参数量较 Mercury 1 扩大 40 倍以上。

**我的点评**：扩散模型的核心卖点是 decode 从逐 token 自回归变成并行去噪，1068 tokens/秒只有长输出和批量并行时才兑现，首 token 延迟未必占优。参数量较 Mercury 1 扩大 40 倍以上，说明它已不是小模型投机路线，而是在赌扩散能用并行补齐质量差距。基准领先是自报口径，缺第三方复现；扩散 LLM 在精确结构化输出上的老问题也没交代。[推测]（置信度：中）

## 二、产品发布/更新（AIHOT）

### 1. DeepSeek 全面开源内部推理框架 DeepInfer

**源站摘要**：DeepSeek 宣布将内部推理框架 DeepInfer 全面开源，并同步开源生产级 Token 编解码组件 deepseek-recipe。

**我的点评**：推理框架开源的影响面通常比模型权重更大：权重决定能不能用，框架决定用起来多贵。DeepInfer 若真含生产级的调度、KV cache 与批处理策略，等于在 vLLM、SGLang 之外公开第三条工程路径，国内团队自建推理栈的成本会明显下降。真正的检验是它是否绑定自家模型结构——只服务 DeepSeek 的框架社区采用率有限，兼容性文档和基准才决定后续。[推测]（置信度：中）

### 2. Google 与 Meta 发布 TorchTPU：PyTorch 原生 TPU 后端

**源站摘要**：Google 与 Meta 发布开源项目 TorchTPU，为 Google TPU 提供原生 PyTorch 后端，模型迁移只需把 .to("cuda") 改为 .to("tpu")。

**我的点评**：换一行 device 字符串就能迁移，价值不在语法糖，而在把 TPU 从 JAX 生态的锁定里解放出来——过去迁 TPU 意味着重写训练栈，这才是最大的采用阻力。Google 与 Meta 联合署名，说明买方和卖方都愿意降低切换成本。但真实的迁移成本从来不只是 device 那行：XLA 图捕获、算子覆盖度、调试工具链才是损耗所在，快照没给这些细节。[推测]（置信度：中）

**来源**：PyTorch：Blog（RSS） · [原始出处](https://pytorch.org/blog/introducing-torchtpu/) · [AIHOT 条目](https://aihot.news/items/lh8vm7yp332xoffhqoscusss4)

### 3. ChatGPT 推出 Locked Chats，可用 PIN 或生物识别锁定敏感对话

**源站摘要**：ChatGPT 推出 Locked Chats 功能，把敏感对话从常规历史记录和搜索中移入受保护空间。用户在网页端和桌面端可用 PIN 解锁，支持的移动设备上可用 PIN、Face ID、Touch ID 或设备解锁；锁定会话中的新消息不会更新常规对话使用的记忆。该功能即日起向 Free、Go、Plus、Pro、Business、Enterprise 和 Edu 套餐推出。

**我的点评**：做成会话隔离加不进记忆，产品方向是对的，但威慑力有限：锁住的是本地界面访问，不是云端数据留存与合规调取，对账号被盗、共享设备这类威胁有帮助，对企业合规审查没帮助。更值得注意的是它明确切断锁定会话与常规记忆的联动，这反过来说明普通对话默认在持续喂养记忆——把记忆当默认、把不记忆当可选特性，这个默认值值得警惕。[推测]（置信度：中）

### 4. Google 发布 vLLM 与 SGLang 的 TorchTPU 原生推理引擎

**源站摘要**：Google 在 PyTorch 相关公告中推出基于 TorchTPU 的 vLLM 和 SGLang 原生 PyTorch 推理引擎，分别与 Inferact、RadixArk 合作开发，让开发者用熟悉的 PyTorch 工具在 TPU 上部署模型。

**我的点评**：推理引擎跟进比训练后端更能决定 TPU 的实际利用率——训练是一次性成本，推理是天天付账。vLLM 和 SGLang 分别拉上 Inferact、RadixArk 共建，等于把社区最主流的两套 serving 栈直接搬上 TPU，绕开了只有 JAX 才能榨干 TPU 的旧假设。需要留意原生 PyTorch 后端在 TPU 上通常要吃 XLA 编译开销和算子缺口，长尾模型的支持度会是分化点。[推测]（置信度：中）
