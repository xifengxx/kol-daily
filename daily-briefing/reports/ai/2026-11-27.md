### 2. Calif 披露 Tor Browser 15.0.22 UAF 漏洞链可致真实 IP 泄露

**源站摘要**：Calif 在 OpenAI Patch the Planet 项目下发布研究，展示恶意网站可通过 UAF 漏洞链绕过 Tor Browser 15.0.22 默认防御，泄露用户真实 IP。

**我的点评**：Tor 的威胁模型默认「恶意网站逃不出浏览器沙箱」，一旦 UAF 链能拿到真实 IP，网络层的匿名性就被绕过去了——这是最省成本的去匿名路径，比流量关联分析便宜得多。更值得记的是它挂在 OpenAI 的 Patch the Planet 名下：AI 实验室出资做进攻性安全研究，正在改变漏洞发现的产能结构。对使用者只有一件事要做：确认版本已修，别把「用了 Tor」当成匿名保证。（置信度：中）

**我的点评**：真正的信号不是地图，而是工作的形状：一个人、7 小时、45K 行、31 个异构公开数据源统一到 25km 六边形网格——被压缩掉的正是过去要花几周的数据清洗与口径对齐。该怀疑的地方也在这：7 小时产出 45K 行，意味着逐行审查几乎不可能，join 与人均归一化的正确性没有验证，一张好看的地图可以掩盖错误的分母。当作 Agent 做 ETL 的样本看，别当地图作品看。（置信度：中）

### 3. 卡兹克把《人生意义设计课》做成AI Prompt，帮你设计人生的意义

**源站摘要**：公众号作者卡兹克将斯坦福《人生意义设计课》新书的核心方法改编成一个多轮对话Prompt，通过四个阶段6到9个问题，最终生成一份5000到7000字的《个人意义设计手册》。他用GPT-6.2完整实测并展示了手册内容，包括意义地图、思维误区重构、罗盘价值观和可执行的意义时刻设计，全程约20到30分钟。

**我的点评**：把一本书的方法论拆成四阶段、6 到 9 个问题的多轮提问，这才是「AI 教练」目前唯一站得住的形式：结构化地逼问，而不是一次性生成。5000 到 7000 字、20 到 30 分钟，产出的大部分其实是对你自己回答的整理与重构，价值取决于你输入的质量。要警惕的是它无法被证伪——「意义」是发现还是被排版出来的，交付物本身回答不了。当思维脚手架用，别当 oracle。（置信度：中）

### 4. Philipp Schmid 撰文解释为何在 Skills 与 CLI 兴起后仍更看好 MCP

**源站摘要**：Philipp Schmid 撰文解释为何在 Skills 和 CLI 流行后依然看好 MCP：Linear 和 Notion 的 agent 每周创建约 240 万条 issue 和页面，Atlassian 每天 MCP 工具调用超 500 万次，其中 44% 用户来自软件团队之外，Notion 报告 60 倍 MCP 流量增长。

**我的点评**：这组数字真正说明的是 MCP 赢在分发而不是优雅：44% 的调用者来自软件团队之外，这批人不会去写 CLI，更不会维护 skill 文件。Skills 和 CLI 在开发者手感上更顺，MCP 在触达上更宽，两者会长期共存而不是替代。但工具调用量和流量增长是使用指标，不是可靠性指标——在那个量级上，鉴权、权限收敛、单工具错误率才是决定它能不能进关键流程的东西。（置信度：中）
