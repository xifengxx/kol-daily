### 1. DeepSeek 开放自研搜索 API

**源站摘要**：DeepSeek 开放自研搜索 API，底层由 AI 原生的 DeepSeek 搜索引擎提供，每天稳定处理数亿次搜索请求。该引擎索引全球千亿级网页、支持多语言，并通过识别机制过滤 SEO 作弊、GEO 操纵和低质 AIGC，使用方式见网页搜索与抓取指南。

**我的点评**：把自研搜索开放成 API，等于把多数 LLM 厂商转售自 Bing/Brave 等的「网页检索」收回自建，成本与排期自控，还多占一个智能体生态入口。真正值钱的是它点名的对治对象——SEO 作弊、GEO 操纵、低质 AIGC，这正是当下 agent 检索最大的污染风险，过滤机制成色直接决定该 API 的口碑。「千亿级网页、日数亿次请求」为源站说法，无第三方核验[待核实]。（置信度：中）
