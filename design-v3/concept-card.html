HBM · 高带宽存储
High Bandwidth Memory · 半导体存储技术
置信度: 高 知识库已收录
一句话解释
HBM是一种将多个DRAM芯片垂直堆叠、通过硅通孔(TSV)技术连接、封装在GPU旁边的新型存储器，专为大模型AI训练所需的海量数据吞吐而设计。与传统DDR内存相比，HBM通过增加数据通道宽度（1024-bit vs 64-bit）和堆叠层数，实现了数量级提升的内存带宽。
生活类比（寓言提示法）
快递驿站升级版：传统DRAM就像「快递站只开1个窗口，包裹一次只能搬一个」，HBM就像「把3个快递站垂直叠成一栋12层大楼，每层都有收发窗口同时运作」。GPU是「收货卡车」，传统方式卡车要排队等货，HBM让卡车直接开进装卸区，同时从12层楼装卸，速度提升24倍。
现实元素类比对象说明
DRAM颗粒快递包裹存储的基本数据单元
TSV硅通孔连接各层的电梯垂直方向的快速通道
GPU收货卡车需要快速获取数据
带宽提升窗口数量从1→121024-bit vs 64-bit
堆叠层数楼层数量HBM3E 12层 → HBM4 16层
专业定义
全称: High Bandwidth Memory（高带宽存储器），由AMD和SK海力士于2013年联合提出，HBM2E后由JEDEC标准化
技术核心: TSV（Through-Silicon Via）硅通孔 + 3D堆叠 + 1024-bit宽总线接口
带宽: HBM3E 达 1.2 TB/s（对比：DDR5 仅 ~50 GB/s，差距约24倍；GDDR6X ~100 GB/s，差距12倍）
容量: 单堆叠 24GB-36GB，GPU搭载4-8堆叠可达 192GB（B200）
功耗: 每GB带宽功耗比GDDR低60%，能效比优异
标准演进: HBM2 (2016) → HBM2E (2018) → HBM3 (2022) → HBM3E (2024) → HBM4 (2026)
供应商格局: SK海力士（52%份额）、三星电子（38%）、美光科技（10%），CR3=100%寡头垄断
市场关注原因（5维度分析）
1. 政策维度: 美国CHIPS法案限制对华先进存储出口（HBM2E及以上），国产替代成为国家战略。中国大基金三期3000亿重点投向存储。
2. 业绩维度: SK海力士2024年HBM收入同比增长320%，占公司总营收35%（2022年仅5%）。美光2024年HBM产能已满至2025年。
3. 事件维度: NVIDIA B200 GPU每台搭载8颗HBM3E（192GB），H200搭载6颗（144GB），需求与GPU出货量刚性绑定。NVIDIA GTC 2026将发布Rubin架构，HBM4需求提前锁定。
4. 情绪维度: AI算力军备竞赛中，HBM被华尔街称为「AI时代的石油」，类比2010年代智能手机中的NAND Flash。
5. 产业链维度: 上游硅料涨价→晶圆成本上升→HBM颗粒涨价→GPU BOM成本增加→AI服务器涨价→云厂商capex增加→终端AI应用成本传导。全链条涨价信号明确。
产业链位置
上游（原材料与设备）: 硅晶圆（信越化学/环球晶圆/沪硅产业）→ 电子特气（林德/空气化工/南大光电）→ 光刻胶（JSR/东京应化/彤程新材）→ TSV设备（应用材料/泛林/中微公司）
中游（制造与封装）: DRAM存储颗粒制造（SK海力士/三星/美光/长鑫存储）→ TSV堆叠与封装（台积电CoWoS/Amkor/通富微电/深科技）
下游（应用）: AI GPU（NVIDIA/AMD/Intel）→ AI服务器（Dell/SMCI/浪潮/工业富联）→ 云计算平台（Azure/AWS/GCP/阿里云）→ 终端AI应用（ChatGPT/Midjourney/企业AI）
产业链定位: AI算力产业链 L2 设备与零部件，是GPU的瓶颈组件。没有HBM，GPU无法发挥算力，属于「卡脖子」环节。

投资关注焦点
• HBM技术迭代节奏: HBM3E → HBM4 的量产时间窗口（2025Q4-2026），HBM4将采用16层堆叠、2nm逻辑芯片
• 产能瓶颈: CoWoS封装产能（台积电）是否成为HBM交付的硬约束。台积电2025年CoWoS产能预计翻倍但仍供不应求
• 国产替代: 长鑫存储HBM技术进展、通富微电/深科技封测良率提升速度。国产HBM2预计2025年流片
• ASP变化: HBM均价每季度环比变化（当前HBM3E约$150-200/GB，HBM4预计$250+/GB）
• 客户结构: NVIDIA GPU出货量（B200/H200）与HBM配比的弹性关系。每颗B200需要8颗HBM3E
• 竞争格局: 三星/美光追赶进度，SK海力士份额能否维持50%+
风险警示
• 技术替代风险: CXL（Compute Express Link）内存互联技术可能在中长期（2027+）替代部分HBM需求，实现内存池化共享
• 周期风险: 存储行业强周期性（3-4年周期），AI需求若放缓（如大模型训练需求饱和），HBM可能面临产能过剩
• 地缘政治风险: 美对华出口管制升级可能影响中国HBM供应链，同时加速中国国产替代（双刃剑）
• 竞争格局恶化: 三星/美光追赶加速，SK海力士份额可能从52%下滑至40%区间
• 估值风险: HBM概念股（如通富微电）2024-2025年已大幅上涨100%+，需警惕追高风险。建议关注估值合理的二线标的
• 技术迭代风险: HBM4若延迟（从2026推至2027），可能影响相关公司业绩兑现节奏

CPO · 共封装光学
Co-Packaged Optics · 光通信下一代技术
展开查看完整卡片
一句话：CPO是将光学引擎（激光器、调制器）与交换芯片（如博通Tomahawk）封装在同一基板上，取代传统可插拔光模块的技术方案。功耗降低30%、带宽密度提升5倍，是AI数据中心800G/1.6T互联的终极方案。
CoWoS · 台积电2.5D封装
Chip on Wafer on Substrate · 先进封装技术
展开查看完整卡片
一句话：CoWoS是台积电专有的2.5D封装技术，将多个芯片（逻辑芯片+HBM）通过硅中介层互联封装在一起，是NVIDIA H100/B200 GPU的必需工艺。当前产能供不应求，被视为AI芯片的「封装瓶颈」。
